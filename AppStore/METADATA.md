## Short description
A 5–15 second puzzle where the instructions might be lying. Can you beat 30 levels?

## Full description
The game tells you what to do.

Sometimes it tells the truth.
Sometimes it doesn't.
Sometimes it uses what you did last time against you.

Each level is a few seconds. Tap, wait, or don't trust the first sentence.

No account. No internet required to play.
